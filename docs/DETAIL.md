# 任意输入框语音输入

把官方的麦克风"借"到用户声明过的输入框旁：提问卡片的作答框、带按钮行的弹窗、快捷键参考页，以及任何加了 `data-voice-input` 或命中配置 `allow` 的普通字段。

官方对话输入框**不接管**：它有自己的麦克风，那是官方逻辑。

## 它复用了什么

- **同一个识别能力**：走官方语音服务（`remote.speech`）的 `catalog` 与 `transcribe`，provider、语言、麦克风偏好、时长与体积上限全部与官方按钮同源；`follow` 流用于保持就绪状态，断流后按退避重试。
- **同一个按钮**：按钮、录音展开行、波形、失败重试、设置弹窗都由官方源码编译而来，外观与操作逻辑一致。
- **同一条录音链路**：官方 `Recording`（16 kHz 单声道 PCM16 WAV）与官方麦克风偏好。

## 哪些位置会出现

| 表面 | 判定 | 位置 |
|---|---|---|
| 提问卡片 | `[data-question-key]` | 页脚动作按钮行左侧；空闲贴右沿，录音时向左生长到页码右侧 |
| 弹窗 | `[role="dialog"][aria-modal="true"]` | 有动作行时同上；没有则贴字段 |
| 快捷键参考页 | `[data-shortcut-modal="shortcuts"]` | 贴字段；录音时接管字段宽度 |
| 普通字段 | `data-voice-input` 或配置 `allow` | 贴字段右缘；录音时接管字段宽度 |

## 哪些位置不会出现

- 设置面板 `[data-shortcut-modal="settings"]` 与其内部一切输入框；
- 账户/平台浮层 `[data-shortcut-modal="platform"]`；
- 设置面板打开期间弹出的其它弹窗（插件安装、模型编辑等，它们 portal 到 body，没有设置祖先）；
- 未注册的普通输入框（默认拒绝）。

## 设置页

「设置」里默认有一页「语音输入」，用于录入触发键（键盘组合、鼠标键、媒体键）。把配置里的 `settingsPage` 写成 `false` 可彻底隐藏；页面内关闭只对当前 revision 生效。

## 注册方式

1. **属性标记**（推荐）：给输入框或它的任意祖先加 `data-voice-input`。
2. **配置文件**：`<profile>/voice-anywhere/config.json` 的 `allow` 写 CSS 选择器；命中字段或祖先即生效。`disable` 可关闭 `question-card`、`dialog`、`shortcuts`。

配置由宿主逐请求读盘，改完重新加载界面即可，不需要重建或重启。

## 交互

- 点击麦克风开始录音，再点停止键转写（或按快捷键）；
- 识别结果**追加**到字段末尾并补一个空格，不覆盖已有内容；
- 录音中按 `Esc`、切走窗口或页面隐藏会取消，不插入任何内容；
- 普通字段录音期间其文字与占位符暂时隐藏，停止后恢复。

## 快捷键

命令「任意输入框语音输入」默认不绑定：键位在「设置 → 快捷键」里自行设置。注册时不提供任何默认值，避免某个平台的保留组合一次性拒绝整条命令。
